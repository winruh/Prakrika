# Prakrika — подготовка к демоэкзамену

## Модуль 1 — БД и диаграммы
Папка Модуль_1_БД_и_диаграммы:

- Вариант_1, Вариант_2, Вариант_3 — база данных (.db) и ER-диаграмма (.drawio)
- Вариант_4_зоотовары — магазин зоотоваров: исходные данные (данные.xlsx), диаграмма, SQL-скрипт заполнения таблиц и скриншоты из pgAdmin
- Практика_день_2 — SQL-скрипт создания таблиц

## Модуль 2 — Python + Tkinter
Папка Модуль_2_Python_Tkinter:

- Задания — учебные задачи (конвертер, визитка, приветствие, счётчик, калькулятор и др.)
- Итоговое_приложение — main.py: приложение с каталогом товаров из PostgreSQL (psycopg2 + Pillow), картинка в папке images
